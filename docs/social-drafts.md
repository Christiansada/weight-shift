## LinkedIn

A decision can look settled until one priority changes.

I built Weight Shift, an open-source workbench for exploring weighted preference scores. Edit options and criteria, vary one weight, and inspect how the leading option changes. The chart uses calculated pairwise crossings, with ties and interval boundaries available for review.

The included venue example is entirely synthetic. Everything is calculated in the browser; you can export the inputs and analysis as JSON. It is a tool for inspecting a scoring model, not a recommendation engine or uncertainty forecast.

Try it: https://christiansada.github.io/weight-shift/
Source: https://github.com/Christiansada/weight-shift

Contributions welcome: score anchors, numerical edge cases and accessibility reviews.
