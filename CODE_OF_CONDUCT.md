# Code of conduct

Treat contributors with respect. Welcome different backgrounds and levels of experience. Discuss ideas and evidence, not personal traits. Harassment, discriminatory language, threats, doxxing and unwanted contact are not acceptable.

Maintainers may remove harmful content and restrict participation proportionately. Report conduct concerns using GitHub's reporting tools; do not publish private details in an issue. Maintainers should explain moderation decisions where doing so does not expose the reporter. This policy applies to repository discussions, issues and pull requests.
